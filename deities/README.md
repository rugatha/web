# 神祇牌卡與信徒名錄

牌卡沿用 template 的共用外框、語言按鈕與品牌 Banner。正面以翻面圖示提示操作；滑鼠移入時輕微浮起並傾斜，觸控裝置不套用 hover 動效。點選正面任一處，牌卡以 3D 翻面顯示背面的 PC／NPC 人物清冊；可點背面空白處、按「翻回正面」或 Escape 回到神像，Enter／空白鍵也可翻面。切換語言保留各卡正反面狀態。背面維持正面尺寸，較長的清冊在背面內捲動，隱藏面使用 inert 排除鍵盤與輔助閱讀焦點。人物姓名直接連往原 PC／NPC 頁，不顯示箭頭；點人物不觸發翻面。減少動態效果的系統偏好會停用懸浮傾斜及旋轉動畫。

首次翻到背面才載入人物資料；成功的資料共用快取，PC、NPC 個別失敗不影響另一組，可按「重新載入」重試。沒有已確認的人物時顯示空狀態，不推定該宗教沒有信徒。

## 人物來源

- NPC：直接讀取 `npc/data/characters.json` 的 `religionZh`／`religionEn`，以完整名稱比對，支援多個宗教並去重。這些欄位可能含過往信仰，名錄有共同說明。蜘蛛神教的人物清冊包含母親大人、阿爾芬諾與安娜；其他宗教維持排除神祇本身的 NPC 記錄。
- PC：直接讀取 `pc/pc_lib` 的 `religion` 字串陣列，支援多個信仰；以 slug、對應的完整中英文神名，以及「神王教」的 `GodKing` 舊名。空陣列 `[]` 表示尚未確認，不從冒險紀錄提及的神名推定信仰。人物名稱也取自同一筆資料，避免另外維護名單。
- 蜘蛛神教：使用合併後的 `spider-religion` 牌卡，讀取「蜘蛛神教」欄位。不自行推定信徒效忠母親大人、安娜或阿爾芬諾。
- 交易、得到神諭、出現神名或被指派任務本身不足以證明信仰；不自動加入。例如米多莉拒絕改信奧提森，不能因與多姆尼爾對話就加入奧提森名錄。

名單更新應回到 PC／NPC 原始欄位。角色頁 URL 分別由 PC 英文名既有 slug 規則及 NPC `url` 取得，神祇數量與分類沿用 `deities.json`，不額外固定。
