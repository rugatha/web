# Melvin、Plus c08 與已上雲圖片地端清理

2026-11-06（台北時間）。依使用者指示，先修復 Melvin 與補上 Plus c08，再清理所有能以雲端 checksum 核對的地端圖片副本。本輪改動納入後續 164 張網站圖片的完整發布批次，最新正式發布狀態見 [完整遷移紀錄](site-migration-2026-11-06.md)。

## 結果

- Melvin 縮圖改用 `thumb-3780b5a0.webp`，閱讀版改用 `reading-c048f1a8.webp`；內容與檔名 checksum 一致，公開回應恢復一年 immutable。人物資料與頁面分享 metadata 已同步。私人原圖改以實際替換來源 `original-d20e7628.jpg` 記錄，移除誤設的下載 token，管理端讀回及匿名拒絕讀取驗證通過。舊公開網址保留供既有頁面使用，worker 也保留舊網址的更新處理。
- Plus c08 封面與第 1、2 章三張原圖已私人備份，六個 WebP 變體已上傳，逐張核對 checksum、標頭、CORS 及原圖匿名不可讀；前端來源與分享圖片均已更新。
- 已預上傳的封面／章節沿用原有變體。本輪合計切換及移除 148 張封面／章節地端原圖，303,590,745 bytes；私人原圖及 296 個公開變體全部重新讀回驗證成功，且網站引用為零，才進行刪除。
- 另清理網站橫幅 `assets/banner/rugatha-banner-trademark.png` 與體驗圖 `assets/banner/rugatha-experience.jpeg`，1,975,710 bytes。橫幅沿用內容相同的現存公開 PNG，另補私人完整備份；體驗圖沿用相同原圖的故事弧備份／閱讀版。
- **共移除 150 張、305,566,455 bytes（305.57 MB／291.41 MiB）。** 刪除清單與 Git diff 的刪除集合完全一致。剩餘網站圖片 205 張；另保留一張供 ColorSync 回歸測試使用的 16×8 CMYK fixture，避免測試依賴已刪除的網站原圖。

對剩餘地端圖片與最新雲端物件 checksum 再次比對，相符副本為零。最新 live objects 為 1,292 個、1,281,359,399 bytes（約 1.28 GB）。完整原圖繼續保留，不刪除雲端原圖、不重寫 Git 歷史。

## 備份與動態引用修復

本輪發現 145 張舊原圖備份實際為 legacy `REGIONAL`，舊 manifest 卻記為 `STANDARD`。已使用 generation 前置條件，以相同內容、私人權限及 `private, no-store` 改成明確 STANDARD，保存新舊 generation 及 checksum 的 [對照清單](archive-class-normalization-2026-11-06.json)。舊 generation 可能依七天軟刪除政策暫時占用容量；live size 不含這些資料。歷史 manifest 不再作為本輪原圖 generation 的依據。

神祇腳本的圖片 fallback 與報名腳本動態組合的 JPEG fallback 已同步到雲端，避免只改 HTML 後仍請求舊檔。報名頁原本優先的當期活動 PNG 保留，只有舊 JPEG fallback 改為雲端閱讀版。

worker 升至 v55，新增僅針對已核對橫幅 PNG 的快取允許規則，讓橫幅在首次瀏覽後仍可離線顯示；沒有開放其他 PNG 或私人圖片快取。既有圖片測試改為從 worker 讀取快取版本，不再寫死 v52。
